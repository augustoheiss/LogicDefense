# 🤖 CV Maker — Agent Skills Oficiais

Este diretório contém as skills canônicas recomendadas para arquitetos e candidatos que utilizam o ecossistema **CV Maker 2.0**.

---

## 📑 Skills Disponíveis

### 1. [`agency-pdf-engine-architect.md`](./agency-pdf-engine-architect.md)
* **Função**: Arquitetura de compilação determinística HTML-to-PDF, anti-rasterização Skia (preservação de DPI em vetores), bisseção matemática de páginas A4 e isolamento de layout sandboxed.
* **Uso Ideal**: Agentes encarregados de geração de documentos paginados, relatórios técnicos, dossiês e PDFs que não podem sofrer quebras arbitrárias ou páginas em branco residuais.

### 2. [`agency-resume-tailor.md`](https://github.com/msitarzewski/agency-agents/blob/main/specialized/resume-tailor.md)
* **Repositório Oficial Upstream**: [msitarzewski/agency-agents](https://github.com/msitarzewski/agency-agents/blob/main/specialized/resume-tailor.md)
* **Função**: Otimização cirúrgica de currículos para Job Descriptions específicas, conformidade com sistemas ATS, fórmulas de impacto Google / IBM X-Y-Z e guardrails absolutos de **Zero Fabricação Factual**.
* **Uso Ideal**: Agentes de carreira, recrutamento e candidatos preparando aplicações de alto nível.

---

## 🔗 Integração em Agentes de IA

* **Claude Desktop**: Adicione os arquivos ao seu *Project Knowledge* ou importe como `SKILL.md`.
* **Cursor / Windsurf**: Referencie o caminho `.cursor/rules/` ou aponte diretamente para este repositório.
* **Antigravity IDE**: Execute diretamente invocando `/{nome-da-skill}`.
